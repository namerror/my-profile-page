# Session Summary
- Added background image support to `ProjectCard` — when a project has an `image_url`, it renders as a layered background behind the card content with dark overlays to preserve text readability.
- For projects without an image, the existing solid dark background style is preserved unchanged.
- Added hover effects: background lightens on hover for both card types; image-backed cards also zoom the image in on hover.
- Updated `next.config.ts` to allow remote image patterns so `next/image` can load backend-hosted `image_url` values.

# Files Touched
- `frontend/app/components/ProjectCard.tsx` — added `image_url` prop destructuring; conditional image/overlay layers; `group`/`group-hover` Tailwind pattern for hover effects; image zoom on hover.
- `frontend/next.config.ts` — added `images.remotePatterns` wildcard for `https://` and `http://` to support external `image_url` sources.

# Tests / Verification
- Not run (no test suite for frontend components; changes are visual only).
