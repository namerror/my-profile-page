# Session Summary
- Migrated project image storage from local disk to Vercel Blob.
- The previous implementation wrote files to `backend/uploads/` and served them via a `StaticFiles` mount — incompatible with Vercel's ephemeral serverless filesystem.
- Images are now uploaded to Vercel Blob via its REST API (`PUT https://blob.vercel-storage.com/{filename}`); the returned public HTTPS URL is stored in the DB. Deletion calls `DELETE https://blob.vercel-storage.com` with the stored URL.
- `StaticFiles` mount removed from `main.py`. `httpx` added as a dependency for making the Blob API calls.
- Frontend thumbnail `src` updated from `${API_URL}${item.image_url}` to `item.image_url` since `image_url` is now a full HTTPS URL.
