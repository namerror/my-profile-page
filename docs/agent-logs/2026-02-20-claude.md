# Session Summary
- Added image upload support to Projects. Each project can now store at most one image.
- Images are uploaded via dedicated endpoints, stored on disk in `backend/uploads/`, and served as static files at `/uploads/<filename>`.
- The `ProjectRead` schema now includes `image_url` (nullable string), populated automatically from the DB column.

# Files Touched
- `backend/app/models_db.py` — Added `image_url: Mapped[str]` (nullable) column to `Project`
- `backend/app/schemas.py` — Added `image_url: Optional[str] = None` to `ProjectRead`
- `backend/app/crud.py` — Added `set_project_image` and `clear_project_image` helpers
- `backend/app/api/projects.py` — Added `POST /projects/{id}/image` and `DELETE /projects/{id}/image` endpoints; `DELETE /projects/{id}` now cleans up the image file on disk
- `backend/app/main.py` — Imported `StaticFiles`, created `backend/uploads/` dir on startup, mounted it at `/uploads`

# Tests / Verification
- Not run (per AGENTS.md, web-based testing is done manually by a human; no automated tests exist for these endpoints)

# Open Questions / Follow-ups
- A database migration must be run to add the `image_url` column: `alembic revision --autogenerate -m "add image_url to projects"` then `alembic upgrade head`
- The `backend/uploads/` directory is not gitignored — consider adding it (or its contents) to `.gitignore`
- Frontend integration not yet done; `image_url` is exposed in `ProjectRead` responses for the frontend to consume
