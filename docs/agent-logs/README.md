# Agent Session Logs

All coding agents must log their changes after every session.

## Location
- Logs live in `docs/agent-logs/`.
- Maintain an index in `docs/agent-logs/index.md`.

## File Naming
- `YYYY-MM-DD-agent.md`
- Example: `2026-02-20-codex.md`
- If multiple sessions per day per agent, append `-2`, `-3`, etc.

## Required Sections
- Session Summary
- Files Touched
- Tests / Verification
- Open Questions / Follow-ups

## Template
Use `docs/agent-logs/template.md`.
